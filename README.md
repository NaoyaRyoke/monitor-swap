# MonitorSwap — モニターのウィンドウ一式を丸ごと入れ替える

指定した2枚のモニターにあるウィンドウを、ホットキー1発で丸ごと入れ替える AutoHotkey v2 スクリプト。
メイン画面で作業しつつ、AIに投げた作業はサブモニターで監視し、介入したいときに入れ替える、という使い方を想定している。

## 前提

- Windows（Freedom）
- [AutoHotkey v2](https://www.autohotkey.com/) がインストールされていること

## 使い方

1. `MonitorSwap.ahk` をダブルクリックで起動（タスクトレイに常駐する）
2. 常駐させたい場合は、`Win+R` → `shell:startup` で開いたフォルダにこのファイルのショートカットを入れる

## キー

モニター番号は画面の **左から右** の順（1, 2, 3）。

| キー | 動作 |
|---|---|
| Win+Shift+F1 | モニター1 ⇄ 2 のウィンドウ一式を入れ替え |
| Win+Shift+F2 | モニター1 ⇄ 3 のウィンドウ一式を入れ替え |
| Win+Shift+F3 | モニター2 ⇄ 3 のウィンドウ一式を入れ替え |

ホットキーを変えたい場合は、スクリプト冒頭の3行を編集する。

## 入れ替えの仕様

- 位置は軸ごとに比率で写像する（メイン 4K 16:9 ⇄ サブ 4K 16:10 の微妙な差も、縦 FHD との交換も吸収する）
- ウィンドウサイズは元のまま。行き先モニターに収まらない分だけ詰める
- 最大化しているウィンドウは、行き先でも最大化し直す
- 最小化しているウィンドウは、最小化のまま「復元したときの位置」だけ入れ替える
- 指定していない3枚目のモニターには一切触らない
- 入れ替え前にアクティブだったウィンドウは、移動後もフォーカスを追従させる
- タスクバーやデスクトップなどのシェル系ウィンドウ、裏に隠れた UWP ウィンドウは対象外

## 注意

- 管理者権限で動いているアプリのウィンドウは、通常権限のスクリプトからは動かせない。その場合はスクリプト自体を「管理者として実行」する（動かせなかったウィンドウは黙ってスキップされるので、入れ替え自体は止まらない）
- モニターの物理配置を Windows の設定で変えた場合、番号はその時点の「左から右」の順で自動的に決まる
